# SS Garden Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the SS Garden building-developer website (home, projects, project detail, landowners, about, contact) as a static Next.js export with a real-time 3D tower hero, deployable to cPanel shared hosting.

**Architecture:** Next.js App Router with `output: 'export'`. Pure logic (project filtering, form validation, tower geometry) lives in small tested modules. The 3D tower is generated procedurally from a seeded function and rendered with react-three-fiber; the same scene is captured headlessly to produce the demo "renders". Other demo images come from Stable Horde and Openverse via scripts driven by one image-plan file. The enquiry form posts to a PHP script.

**Tech Stack:** Next.js (App Router, static export), React, TypeScript, Tailwind v4, Motion (`motion/react`), GSAP + ScrollTrigger, three + @react-three/fiber, Phosphor icons, Vitest, Playwright (capture and screenshots), sharp, tsx.

**Spec:** `docs/superpowers/specs/2026-10-21-ss-garden-website-design.md`

**Working directory for every command:** `C:\Users\amiba\Projects\SS Gardens` (commands are Git Bash syntax).

**Global rules for every task**
- Zero em-dashes or en-dashes in any source file (a test enforces this). Use a hyphen, comma or period.
- Sharp corners everywhere: never use `rounded-*` classes.
- One accent colour (the `accent` token). Never hard-code colours in components; use tokens.
- Icons only from `@phosphor-icons/react` (client files) or `@phosphor-icons/react/dist/ssr` (server files), stroke weight `regular` everywhere.
- Anything that moves honours `prefers-reduced-motion`. Never add `window.addEventListener("scroll", ...)`.
- Commit after every task. Commit messages carry no Co-Authored-By line or any other attribution trailer.

Create `scripts/fetch-fonts.mjs`:

```js
import fs from "node:fs";
import path from "node:path";

const css = await (
  await fetch(
    "https://api.fontshare.com/v2/css?f[]=cabinet-grotesk@500,700,800&f[]=satoshi@400,500,700&display=swap",
    { headers: { "User-Agent": "Mozilla/5.0" } },
  )
).text();

fs.mkdirSync("public/fonts", { recursive: true });
const blocks = css.match(/@font-face\s*{[^}]*}/g) ?? [];
if (blocks.length === 0) throw new Error("No @font-face blocks returned");

let out = "/* Generated by scripts/fetch-fonts.mjs. Fonts: Fontshare, free for commercial use. */\n";
for (const block of blocks) {
  const family = /font-family:\s*['"]?([^;'"]+)/.exec(block)[1].trim();
  const weight = /font-weight:\s*([0-9]+)/.exec(block)[1];
  const url = /url\(['"]?([^'")]+\.woff2[^'")]*)['"]?\)/.exec(block)[1];
  const file = `${family.toLowerCase().replace(/\s+/g, "-")}-${weight}.woff2`;
  const res = await fetch(url.startsWith("//") ? `https:${url}` : url);
  fs.writeFileSync(path.join("public/fonts", file), Buffer.from(await res.arrayBuffer()));
  out += `@font-face{font-family:"${family}";font-weight:${weight};font-style:normal;font-display:swap;src:url("/fonts/${file}") format("woff2");}\n`;
  console.log("saved", file);
}
fs.writeFileSync("src/app/fonts.css", out);
```

```ts
import { describe, it, expect } from "vitest";
import fs from "node:fs";
import path from "node:path";

function walk(dir: string): string[] {
  return fs.readdirSync(dir, { withFileTypes: true }).flatMap((e) => {
    const p = path.join(dir, e.name);
    if (e.isDirectory()) return walk(p);
    return /\.(ts|tsx|css|php|json)$/.test(e.name) ? [p] : [];
  });
}

describe("copy rules", () => {
  it("has no em-dashes or en-dashes in source or the PHP endpoint", () => {
    const files = [...walk("src"), "public/api/enquiry.php"].filter((f) => fs.existsSync(f));
    const offenders: string[] = [];
    for (const f of files) {
      fs.readFileSync(f, "utf8").split("\n").forEach((line, i) => {
        if (/[\u2013\u2014]/.test(line)) offenders.push(`${f}:${i + 1}`);
      });
    }
    expect(offenders).toEqual([]);
  });
});
```

```ts
import type { Project, ProjectStatus, ProjectType } from "../data/types";

export type StatusFilter = ProjectStatus | "all";
export type TypeFilter = ProjectType | "all";

export const PAGE_SIZE = 6;

const STATUSES: ProjectStatus[] = ["ongoing", "upcoming", "completed"];
const TYPES: ProjectType[] = ["residential", "commercial", "duplex-villa"];

export function parseStatus(v: string | null): StatusFilter {
  return STATUSES.includes(v as ProjectStatus) ? (v as ProjectStatus) : "all";
}

export function parseType(v: string | null): TypeFilter {
  return TYPES.includes(v as ProjectType) ? (v as ProjectType) : "all";
}

export function filterProjects(
  list: Project[],
  f: { status: StatusFilter; type: TypeFilter },
): Project[] {
  return list.filter(
    (p) => (f.status === "all" || p.status === f.status) && (f.type === "all" || p.type === f.type),
  );
}

export function paginate<T>(list: T[], page: number, size: number): { items: T[]; hasMore: boolean } {
  const end = page * size;
  return { items: list.slice(0, end), hasMore: list.length > end };
}

export function countByStatus(list: Project[]): Record<ProjectStatus, number> {
  const out: Record<ProjectStatus, number> = { ongoing: 0, upcoming: 0, completed: 0 };
  for (const p of list) out[p.status] += 1;
  return out;
}
```

```ts
export const INTERESTS = ["buy", "landowner", "commercial"] as const;
export type Interest = (typeof INTERESTS)[number];

export const interestLabel: Record<Interest, string> = {
  buy: "Buying a home",
  landowner: "I own a plot",
  commercial: "Commercial space",
};

export interface EnquiryValues {
  name: string;
  phone: string;
  interest: Interest;
  message: string;
  plot: string;
}

export type EnquiryErrors = Partial<Record<keyof EnquiryValues, string>>;

export function validateEnquiry(v: EnquiryValues): EnquiryErrors {
  const e: EnquiryErrors = {};
  const name = v.name.trim();
  const phone = v.phone.trim();
  const message = v.message.trim();
  const plot = v.plot.trim();

  if (name.length < 2 || name.length > 80) e.name = "Enter your name (2 to 80 characters).";
  if (!/^[0-9+\-\s()]{7,20}$/.test(phone)) e.phone = "Enter a valid phone number, for example +880 1712-345678.";
  if (!INTERESTS.includes(v.interest)) e.interest = "Choose what you are enquiring about.";
  if (message.length < 5 || message.length > 2000) e.message = "Write a short message (5 to 2000 characters).";
  if (v.interest === "landowner" && plot.length < 3) e.plot = "Tell us where the plot is and how large it is.";
  if (plot.length > 300) e.plot = "Keep this under 300 characters.";
  return e;
}
```

```tsx
"use client";

import { motion, useReducedMotion } from "motion/react";

export function Reveal({
  children,
  delay = 0,
  inView = true,
  className,
}: {
  children: React.ReactNode;
  delay?: number;
  inView?: boolean;
  className?: string;
}) {
  const reduce = useReducedMotion();
  const initial = reduce ? false : { opacity: 0, y: 24 };
  const transition = { duration: 0.7, delay, ease: [0.16, 1, 0.3, 1] as const };

  if (inView) {
    return (
      <motion.div
        className={className}
        initial={initial}
        whileInView={{ opacity: 1, y: 0 }}
        viewport={{ once: true, amount: 0.25 }}
        transition={transition}
      >
        {children}
      </motion.div>
    );
  }
  return (
    <motion.div className={className} initial={initial} animate={{ opacity: 1, y: 0 }} transition={transition}>
      {children}
    </motion.div>
  );
}
```

```tsx
import { useEffect, useState } from "react";
import { Moon, Sun } from "@phosphor-icons/react";

export function ThemeToggle() {
  const [dark, setDark] = useState(false);

  useEffect(() => {
    const t = document.documentElement.dataset.theme;
    setDark(t ? t === "dark" : window.matchMedia("(prefers-color-scheme: dark)").matches);
  }, []);

  function toggle() {
    const next = dark ? "light" : "dark";
    document.documentElement.dataset.theme = next;
    try {
      localStorage.setItem("theme", next);
    } catch {}
    setDark(!dark);
  }

  return (
    <button
      type="button"
      onClick={toggle}
      aria-label={dark ? "Switch to light theme" : "Switch to dark theme"}
      className="flex h-10 w-10 items-center justify-center border border-line transition active:scale-[0.96] hover:border-text focus-visible:outline-2 focus-visible:outline-accent"
    >
      {dark ? <Sun size={20} /> : <Moon size={20} />}
```

```ts
export type Vec3 = [number, number, number];
export interface Box { p: Vec3; s: Vec3 }
export interface Foliage { p: Vec3; r: number; tone: number }
export interface TowerGeometry {
  base: Box[];
  slabs: Box[];
  glass: Box[];
  columns: Box[];
  planters: Box[];
  trunks: Box[];
  foliage: Foliage[];
  height: number;
}

export const TOWER = { W: 4.2, D: 2.8, FH: 0.52, T: 0.1 } as const;

export function mulberry32(seed: number) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function buildTower(floors: number, seed: number): TowerGeometry {
  const { W, D, FH, T } = TOWER;
  const rng = mulberry32(seed);
  const g: TowerGeometry = {
    base: [], slabs: [], glass: [], columns: [], planters: [], trunks: [], foliage: [],
    height: floors * FH,
  };

  const tree = (x: number, y: number, z: number, scale: number) => {
    const trunkH = 0.22 * scale;
    g.trunks.push({ p: [x, y + trunkH / 2, z], s: [0.04 * scale, trunkH, 0.04 * scale] });
    const crown = 0.13 * scale + rng() * 0.05 * scale;
    g.foliage.push({ p: [x, y + trunkH + crown * 0.8, z], r: crown, tone: Math.floor(rng() * 4) });
  };

  g.base.push({ p: [0, -0.3, 0], s: [W + 3, 0.6, D + 3] });

  for (let i = 0; i < floors; i++) {
    const y = i * FH;
    const ext = i % 3 === 0 ? 0.45 : 0;
    g.slabs.push({ p: [0, y, ext / 2], s: [W, T, D + ext] });
    g.glass.push({ p: [0, y + FH / 2, 0], s: [W - 0.12, FH - T, D - 0.12] });
    for (const sx of [-1, 1]) {
      for (const sz of [-1, 1]) {
        g.columns.push({ p: [sx * (W / 2 - 0.08), y + FH / 2, sz * (D / 2 - 0.08)], s: [0.14, FH, 0.14] });
      }
    }
    if (ext > 0 || i % 2 === 0) {
      const z = D / 2 + ext - 0.12;
      const len = W * 0.92;
      g.planters.push({ p: [0, y + T / 2 + 0.08, z], s: [len, 0.16, 0.22] });
      const n = Math.floor(len / 0.5);
      for (let k = 0; k < n; k++) {
        const x = -len / 2 + (k + 0.5) * (len / n) + (rng() - 0.5) * 0.1;
        tree(x, y + T / 2 + 0.16, z, 0.8 + rng() * 0.6);
      }
    }
    if (i % 2 === 1) {
      const x = W / 2 - 0.1;
      g.planters.push({ p: [x, y + T / 2 + 0.08, 0], s: [0.22, 0.16, D * 0.8], });
      for (let k = 0; k < 3; k++) tree(x, y + T / 2 + 0.16, -D * 0.3 + k * D * 0.3, 0.8 + rng() * 0.5);
    }
  }

  const roofY = floors * FH;
  g.slabs.push({ p: [0, roofY, 0], s: [W + 0.3, T, D + 0.3] });
  for (const sx of [-1, 1]) {
    for (const sz of [-1, 1]) {
      g.columns.push({ p: [sx * (W / 2 - 0.3), roofY + 0.3, sz * (D / 2 - 0.3)], s: [0.08, 0.6, 0.08] });
    }
  }
  for (const sz of [-1, 1]) {
    g.columns.push({ p: [0, roofY + 0.62, sz * (D / 2 - 0.3)], s: [W - 0.6, 0.06, 0.08] });
  }
  for (let k = 0; k < 5; k++) {
    tree((rng() - 0.5) * (W - 0.8), roofY + T / 2, (rng() - 0.5) * (D - 0.8), 1.3);
  }

  for (let k = 0; k < 16; k++) {
    const a = (k / 16) * Math.PI * 2 + rng() * 0.2;
    tree(Math.cos(a) * (W / 2 + 2.2), 0, Math.sin(a) * (D / 2 + 2.2), 1.6 + rng());
  }

  return g;
}
```

```tsx
import { Canvas, useFrame, useThree } from "@react-three/fiber";
import * as THREE from "three";
import { buildTower, type Box, type Foliage, type TowerGeometry } from "./tower-geometry";

export interface TowerSceneProps {
  floors: number;
  seed: number;
  sky: "day" | "dusk";
  az: number;
  el: number;
  dist: number;
  quality?: "high" | "low";
  frameloop?: "always" | "never";

  float?: boolean;
  pointer?: { current: { x: number; y: number } };
  scroll?: { current: number };
  onReady?: () => void;
}

const FOLIAGE_TONES = ["#2f7d1a", "#3f9124", "#5aa832", "#256012"].map((c) => new THREE.Color(c));

function Boxes({ items, shadow = true, children }: { items: Box[]; shadow?: boolean; children: React.ReactNode }) {
  const ref = useRef<THREE.InstancedMesh>(null);
  useLayoutEffect(() => {
    const mesh = ref.current;
    if (!mesh) return;
    const o = new THREE.Object3D();
    items.forEach((b, i) => {
      o.position.set(...b.p);
      o.scale.set(...b.s);
      o.updateMatrix();
      mesh.setMatrixAt(i, o.matrix);
    });
    mesh.instanceMatrix.needsUpdate = true;
  }, [items]);
  return (
    <instancedMesh ref={ref} args={[undefined, undefined, items.length]} castShadow={shadow} receiveShadow>
      <boxGeometry />
      {children}
    </instancedMesh>
  );
}

function Crowns({ items }: { items: Foliage[] }) {
  const ref = useRef<THREE.InstancedMesh>(null);
  useLayoutEffect(() => {
    const mesh = ref.current;
    if (!mesh) return;
    const o = new THREE.Object3D();
    items.forEach((f, i) => {
      o.position.set(...f.p);
      o.scale.setScalar(f.r);
      o.updateMatrix();
      mesh.setMatrixAt(i, o.matrix);
      mesh.setColorAt(i, FOLIAGE_TONES[f.tone]);
    });
    mesh.instanceMatrix.needsUpdate = true;
    if (mesh.instanceColor) mesh.instanceColor.needsUpdate = true;
  }, [items]);
  return (
    <instancedMesh ref={ref} args={[undefined, undefined, items.length]} castShadow receiveShadow>
      <icosahedronGeometry args={[1, 1]} />
      <meshStandardMaterial color="#ffffff" flatShading roughness={0.9} />
    </instancedMesh>
  );
}

function Tower({ geo, dusk, float }: { geo: TowerGeometry; dusk: boolean; float: boolean }) {
  const group = useRef<THREE.Group>(null);
  useFrame(({ clock }) => {
    if (float && group.current) group.current.position.y = Math.sin(clock.elapsedTime * 0.6) * 0.05;
  });
  return (
    <group ref={group}>
      <Boxes items={geo.base}><meshStandardMaterial color="#c9cec4" roughness={1} /></Boxes>
      <Boxes items={geo.slabs}><meshStandardMaterial color="#e8ebe4" roughness={0.9} /></Boxes>
      <Boxes items={geo.columns}><meshStandardMaterial color="#d3d7cd" roughness={0.9} /></Boxes>
      <Boxes items={geo.planters}><meshStandardMaterial color="#7d8279" roughness={1} /></Boxes>
      <Boxes items={geo.trunks}><meshStandardMaterial color="#5b4a3a" roughness={1} /></Boxes>
      <Crowns items={geo.foliage} />
      <Boxes items={geo.glass} shadow={false}>
        <meshStandardMaterial
          color="#7fa39a"
          transparent
          opacity={0.55}
          roughness={0.15}
          metalness={0.3}
          emissive={dusk ? "#ffcf8a" : "#000000"}
          emissiveIntensity={dusk ? 0.45 : 0}
        />
      </Boxes>
    </group>
  );
}

function Rig({
  az, el, dist, height, pointer, scroll, onReady,
}: {
  az: number; el: number; dist: number; height: number;
  pointer?: { current: { x: number; y: number } };
  scroll?: { current: number };
  onReady?: () => void;
}) {
  const camera = useThree((s) => s.camera);
  const smooth = useRef({ x: 0, y: 0 });
  const target = useRef(new THREE.Vector3());
  const frames = useRef(0);

  useFrame((_, dt) => {
    const sp = scroll?.current ?? 0;
    smooth.current.x = THREE.MathUtils.damp(smooth.current.x, pointer?.current.x ?? 0, 4, dt);
    smooth.current.y = THREE.MathUtils.damp(smooth.current.y, pointer?.current.y ?? 0, 4, dt);
    const a = THREE.MathUtils.degToRad(az + sp * 40 + smooth.current.x * 6);
    const e = THREE.MathUtils.degToRad(el - smooth.current.y * 3);
    target.current.set(0, height * 0.45, 0);
    camera.position.set(
      Math.sin(a) * Math.cos(e) * dist,
      target.current.y + Math.sin(e) * dist,
      Math.cos(a) * Math.cos(e) * dist,
    );
    camera.lookAt(target.current);
    frames.current += 1;
    if (frames.current === 3) onReady?.();
  });
  return null;
}

export default function TowerScene({
  floors, seed, sky, az, el, dist,
  quality = "high", frameloop = "always", dpr = [1, 2], float = false,
  pointer, scroll, onReady,

  return (
    <Canvas
      shadows={shadows}
      dpr={dpr}
      frameloop={frameloop}
      camera={{ fov: 34, near: 0.1, far: 200, position: [0, 6, dist] }}
      gl={{ antialias: true, powerPreference: "high-performance" }}
      style={{ width: "100%", height: "100%" }}
    >
      <color attach="background" args={[bg]} />
      <fog attach="fog" args={[bg, dist * 1.4, dist * 4]} />
      <hemisphereLight args={[dusk ? "#8aa0c0" : "#ffffff", dusk ? "#2a2218" : "#a8b59a", dusk ? 0.55 : 0.9]} />
      <directionalLight
        position={dusk ? [-8, 5, 6] : [7, 12, 8]}
        intensity={dusk ? 1.4 : 2.2}
        color={dusk ? "#ffb27a" : "#fff4e0"}
        castShadow={shadows}
        shadow-mapSize={[2048, 2048]}
        shadow-camera-left={-12}
        shadow-camera-right={12}
        shadow-camera-top={12}
        shadow-camera-bottom={-12}
        shadow-camera-near={0.5}
        shadow-camera-far={40}
      />
      <Tower geo={geo} dusk={dusk} float={float} />

}
```

```ts
const PORT = 3100;
const BASE = `http://localhost:${PORT}`;

async function waitFor(url: string, ms = 120000) {
  const start = Date.now();
  while (Date.now() - start < ms) {
    try {
      const r = await fetch(url);
      if (r.ok) return;
    } catch {}
    await new Promise((r) => setTimeout(r, 1000));
  }
  throw new Error("dev server did not become ready");
}

async function main() {
  const only = process.argv.slice(2);
  const slots = imageSlots.filter(
    (s) => s.source === "render" && (only.length === 0 || only.some((o) => s.src.includes(o))),
  );
  if (slots.length === 0) {
    console.log("No matching render slots");
    return;
  }

  const server = spawn("npx", ["next", "dev", "-p", String(PORT)], { shell: true, stdio: "ignore" });
  try {
    await waitFor(`${BASE}/dev-tower/`);
    const browser = await chromium.launch({
      args: ["--use-angle=swiftshader", "--enable-unsafe-swiftshader", "--ignore-gpu-blocklist", "--enable-webgl"],
    });
    for (const s of slots) {
      const r = s.render!;
      const page = await browser.newPage({ viewport: { width: s.w, height: s.h }, deviceScaleFactor: 1 });
      const q = new URLSearchParams({
        floors: String(r.floors), seed: String(r.seed), sky: r.sky,
        az: String(r.az), el: String(r.el), dist: String(r.dist),
      });
      await page.goto(`${BASE}/dev-tower/?${q}`);
      await page.waitForFunction(() => (window as unknown as { __towerReady?: boolean }).__towerReady === true, null, { timeout: 90000 });
      await page.waitForTimeout(600);
      const png = await page.screenshot({ type: "png" });
      const out = path.join("public", s.src);
      fs.mkdirSync(path.dirname(out), { recursive: true });
      await sharp(png).webp({ quality: 82 }).toFile(out);
      await page.close();
      console.log("rendered", s.src);
    }
    await browser.close();
  } finally {
    if (process.platform === "win32" && server.pid) {
      try { execSync(`taskkill /pid ${server.pid} /T /F`, { stdio: "ignore" }); } catch {}
    } else {
      server.kill();
    }
  }
}
```

Anonymous Stable Horde users are capped at 637x637 px, so these slots are 576x384. A free AI Horde API key (set `HORDE_API_KEY`) allows larger sizes; if one is supplied, raise the `w`/`h` of the `horde` slots in `image-plan.ts` to 1024x640 first.

- [ ] **Step 1: Write the generator**

Create `scripts/generate-horde.ts`:

```ts
import fs from "node:fs";
import path from "node:path";
import sharp from "sharp";
import { imageSlots } from "../src/data/image-plan";

const API = "https://aihorde.net/api/v2";
const KEY = process.env.HORDE_API_KEY ?? "0000000000";
const HEADERS = { apikey: KEY, "Client-Agent": "ssgarden:1:site", "Content-Type": "application/json" };
const NEGATIVE = "blurry, text, watermark, logo, low quality, cartoon, people, deformed, distorted";
const CANDIDATES = 2;
const CONCURRENCY = 3;

const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));

async function submit(prompt: string, w: number, h: number): Promise<string> {
  for (;;) {
    const res = await fetch(`${API}/generate/async`, {
      method: "POST",
      headers: HEADERS,
      body: JSON.stringify({
        prompt: `${prompt} ### ${NEGATIVE}`,
        params: { width: w, height: h, steps: 25, n: CANDIDATES, sampler_name: "k_euler_a", cfg_scale: 6 },
        nsfw: false, trusted_workers: false, slow_workers: true, r2: true,
      }),
    });
    if (res.status === 429) { await sleep(15000); continue; }
    const j = await res.json();
    if (!res.ok) throw new Error(JSON.stringify(j));
    return j.id as string;
  }
}

async function waitDone(id: string) {
  for (;;) {
    const j = await (await fetch(`${API}/generate/check/${id}`)).json();
    if (j.faulted) throw new Error(`job ${id} faulted`);
    if (j.done) return;
    await sleep(8000);
  }
}

async function runSlot(src: string, prompt: string, w: number, h: number) {
  const id = await submit(prompt, w, h);
  console.log("submitted", src);
  await waitDone(id);
  const j = await (await fetch(`${API}/generate/status/${id}`)).json();
  const gens = (j.generations ?? []) as { img: string }[];
  const dir = path.join(".cache", "horde");
  fs.mkdirSync(dir, { recursive: true });
  for (let k = 0; k < gens.length; k++) {
    const buf = Buffer.from(await (await fetch(gens[k].img)).arrayBuffer());
    const file = path.join(dir, `${src.replace(/[\\/]/g, "_")}-${k + 1}.webp`);
    await sharp(buf).webp({ quality: 90 }).toFile(file);
    console.log("saved", file);
  }
}

async function main() {
  const only = process.argv.slice(2);
  const slots = imageSlots.filter(
    (s) => s.source === "horde" && s.prompt && (only.length === 0 || only.some((o) => s.src.includes(o))),
  );
  if (KEY === "0000000000") {
    for (const s of slots) {
      if (s.w > 637 || s.h > 637 || s.w * s.h > 637 * 637) {
        throw new Error(`${s.src} is ${s.w}x${s.h}; anonymous Horde users are limited to 637x637`);
      }
    }
  }
  for (let i = 0; i < slots.length; i += CONCURRENCY) {
    await Promise.all(slots.slice(i, i + CONCURRENCY).map((s) => runSlot(s.src, s.prompt!, s.w, s.h)));
  }
}

main().catch((e) => { console.error(e); process.exit(1); });
```

```ts
import fs from "node:fs";
import path from "node:path";
import sharp from "sharp";
import { imageSlots } from "../src/data/image-plan";

interface Hit {
  id: string; title: string | null; creator: string | null; license: string;
  license_version: string; url: string; foreign_landing_url: string; width: number | null;
}

const UA = { "User-Agent": "ssgarden-site/1.0" };
const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));

async function search(query: string, license: string, minWidth: number): Promise<Hit[]> {
  const u = new URL("https://api.openverse.org/v1/images/");
  u.searchParams.set("q", query);
  u.searchParams.set("license", license);
  u.searchParams.set("category", "photograph");
  u.searchParams.set("size", "large");
  u.searchParams.set("page_size", "20");
  const r = await fetch(u, { headers: UA });
  if (!r.ok) return [];
  const j = await r.json();
  return ((j.results ?? []) as Hit[]).filter((x) => (x.width ?? 0) >= minWidth);
}

async function main() {
  const force = process.argv.includes("--force");
  const used = new Set<string>();
  const rows: string[] = [];
  const attribution: unknown[] = [];

  for (const s of imageSlots.filter((x) => x.source === "openverse" && x.query)) {
    const out = path.join("public", s.src);
    let hits = await search(s.query!, "cc0,pdm", s.w);
    if (hits.length === 0) hits = await search(s.query!, "by", s.w);
    let done = false;
    for (const h of hits.filter((x) => !used.has(x.id)).slice(0, 5)) {
      try {
        const res = await fetch(h.url, { headers: UA });
        if (!res.ok) continue;
        const buf = Buffer.from(await res.arrayBuffer());
        const meta = await sharp(buf).metadata();
        if ((meta.width ?? 0) < s.w * 0.9) continue;
        const exists = fs.existsSync(out);
        const isPlaceholder = exists && fs.statSync(out).size < 30000;
        if (!force && exists && !isPlaceholder) { done = true; break; }
        fs.mkdirSync(path.dirname(out), { recursive: true });
        await sharp(buf).resize(s.w, s.h, { fit: "cover" }).webp({ quality: 82 }).toFile(out);
        used.add(h.id);
        const lic = `${h.license}${h.license_version ? ` ${h.license_version}` : ""}`;
        rows.push(`| ${s.src} | ${h.title ?? "Untitled"} | ${h.creator ?? "Unknown"} | ${lic.toUpperCase()} | ${h.foreign_landing_url} |`);
        if (!["cc0", "pdm"].includes(h.license)) {
          attribution.push({ src: s.src, title: h.title ?? "Untitled", creator: h.creator ?? "Unknown", license: lic, url: h.foreign_landing_url });
        }
        console.log("saved", s.src, "from", h.foreign_landing_url);
        done = true;
        break;
      } catch {}
    }
    if (!done) console.log("NO MATCH, keeping placeholder:", s.src, `(${s.query})`);
    await sleep(1000);
  }

  if (rows.length > 0) {
    const header = "# Image credits\n\nPhotos found through Openverse. CC0 and public-domain photos need no credit; others are credited in the site footer.\n\n| Slot | Title | Creator | Licence | Source |\n|---|---|---|---|---|\n";
    fs.appendFileSync("CREDITS.md", fs.existsSync("CREDITS.md") ? rows.join("\n") + "\n" : header + rows.join("\n") + "\n");
    const existing = JSON.parse(fs.readFileSync("src/data/credits.json", "utf8")) as unknown[];
    fs.writeFileSync("src/data/credits.json", JSON.stringify([...existing, ...attribution], null, 2) + "\n");
  }
}

main().catch((e) => { console.error(e); process.exit(1); });
```

```tsx
"use client";

import dynamic from "next/dynamic";
import Image from "next/image";
import { useEffect, useRef, useState } from "react";
import { scroll } from "motion";
import type { ImageRef } from "@/data/types";

const TowerScene = dynamic(() => import("../three/TowerScene"), { ssr: false });

function hasWebGL() {
  try {
    const c = document.createElement("canvas");
    return !!(c.getContext("webgl2") || c.getContext("webgl"));
  } catch {
    return false;
  }
}

export function HeroTower({ still }: { still: ImageRef }) {
  const wrap = useRef<HTMLDivElement>(null);
  const pointer = useRef({ x: 0, y: 0 });
  const scrollProgress = useRef(0);
  const [enabled, setEnabled] = useState(false);
  const [ready, setReady] = useState(false);
  const [visible, setVisible] = useState(true);
  const [coarse, setCoarse] = useState(false);

  useEffect(() => {
    const reduce = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
    setCoarse(window.matchMedia("(pointer: coarse)").matches);
    setEnabled(!reduce && hasWebGL());
  }, []);

  useEffect(() => {
    const el = wrap.current;
    if (!enabled || !el) return;

    const io = new IntersectionObserver(([entry]) => setVisible(entry.isIntersecting));
    io.observe(el);

    const onMove = (ev: PointerEvent) => {
      if (ev.pointerType !== "mouse") return;
      const r = el.getBoundingClientRect();
      pointer.current.x = ((ev.clientX - r.left) / r.width) * 2 - 1;
      pointer.current.y = ((ev.clientY - r.top) / r.height) * 2 - 1;
    };
    const onLeave = () => {
      pointer.current.x = 0;
      pointer.current.y = 0;
    };
    el.addEventListener("pointermove", onMove);
    el.addEventListener("pointerleave", onLeave);

    const stop = scroll(
      (progress: number) => {
        scrollProgress.current = progress;
      },
      { target: el, offset: ["start start", "end start"] },
    );

    return () => {
      io.disconnect();
      el.removeEventListener("pointermove", onMove);
      el.removeEventListener("pointerleave", onLeave);
      stop();
    };
  }, [enabled]);

  return (
    <div ref={wrap} className="relative h-full w-full overflow-hidden bg-surface">
      <Image
        src={still.src}
        alt={still.alt}
        width={still.width}
        height={still.height}
        priority
        className="absolute inset-0 h-full w-full object-cover"
      />
      {enabled && (
        <div
          aria-hidden="true"
          className={`absolute inset-0 transition-opacity duration-700 ${ready ? "opacity-100" : "opacity-0"}`}
        >
          <TowerScene
            floors={14}
            seed={11}
            sky="day"
            az={28}
            el={14}
            dist={13}
            quality={coarse ? "low" : "high"}
            dpr={coarse ? [1, 1.25] : [1, 1.75]}
            frameloop={visible ? "always" : "never"}
            float
            pointer={pointer}
            scroll={scrollProgress}
            onReady={() => setReady(true)}
          />
        </div>
      )}
    </div>
  );
}
```

```tsx
  id, label, error, help, children,

  return (

    </div>

export function EnquiryForm({
  variant = "general",
  project = "",
  defaultInterest = "buy",
}: {
  variant?: "general" | "landowner";
  project?: string;
  defaultInterest?: Interest;
}) {
  const [values, setValues] = useState<EnquiryValues>({
    name: "", phone: "", message: "", plot: "",
    interest: variant === "landowner" ? "landowner" : defaultInterest,
  });
  const [errors, setErrors] = useState<EnquiryErrors>({});
  const [status, setStatus] = useState<Status>("idle");
  const done = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (status === "success") done.current?.focus();
  }, [status]);

  const set = <K extends keyof EnquiryValues>(k: K, v: EnquiryValues[K]) => setValues((p) => ({ ...p, [k]: v }));
  const describe = (id: string, e?: string, help?: boolean) => (e ? `${id}-error` : help ? `${id}-help` : undefined);

  async function onSubmit(e: React.FormEvent<HTMLFormElement>) {
    e.preventDefault();
    if (new FormData(e.currentTarget).get("website")) {
      setStatus("success");
      return;
    }
    const errs = validateEnquiry(values);
    setErrors(errs);
    if (Object.keys(errs).length > 0) return;

      if (process.env.NEXT_PUBLIC_MOCK_FORM === "1") {

          body: JSON.stringify({ ...values, project }),
        });
        const data = await res.json();
        if (!res.ok || !data.ok) throw new Error(data.error ?? "Request failed");
      }
      setStatus("success");
    } catch {
      setStatus("error");
    }
  }

  if (status === "success") {
    return (
      <div ref={done} tabIndex={-1} role="status" className="border border-text p-6 outline-none">
        <p className="font-display text-2xl">Thank you.</p>
        <p className="mt-2 text-muted">We have your enquiry and will call you on {values.phone || "the number you gave"}.</p>
      </div>
    );
  }

  return (
    <form onSubmit={onSubmit} noValidate className="grid gap-5">
      <div className="absolute -left-[9999px]" aria-hidden="true">
        <label htmlFor="website">Leave this field empty</label>
        <input id="website" name="website" tabIndex={-1} autoComplete="off" />
      </div>

      {project && <p className="text-sm text-muted">Enquiring about {project}.</p>}

      </Field>

            onChange={(e) => set("interest", e.target.value as Interest)}>
```

- [ ] **Step 2: Write the PHP endpoint**

It repeats the rules in `src/lib/enquiry.ts`. Set `$TO` to the company's real inbox before deploying.

Create `public/api/enquiry.php`:

```php
<?php
declare(strict_types=1);

header('Content-Type: application/json; charset=utf-8');
header('X-Content-Type-Options: nosniff');

// The address that receives enquiries. Set this before deploying.
$TO = 'CHANGE_ME@yourdomain.com';
const MAX_PER_WINDOW = 3;
const WINDOW_SECONDS = 600;
const INTERESTS = ['buy' => 'Buying a home', 'landowner' => 'I own a plot', 'commercial' => 'Commercial space'];

function respond(int $code, array $body): void {
    http_response_code($code);
    echo json_encode($body);
    exit;
}

function clean(mixed $value, int $max): string {
    $s = preg_replace('/[\r\n]+/', ' ', (string) $value) ?? '';
    return mb_substr(trim($s), 0, $max);
}

if (($_SERVER['REQUEST_METHOD'] ?? '') !== 'POST') {
    respond(405, ['ok' => false, 'error' => 'Method not allowed.']);
}

$data = json_decode(file_get_contents('php://input') ?: '', true);
if (!is_array($data)) {
    respond(400, ['ok' => false, 'error' => 'Invalid request.']);
}

// Honeypot: real visitors never fill this field.
if (!empty($data['website'])) {
    respond(200, ['ok' => true]);
}

$ip = $_SERVER['REMOTE_ADDR'] ?? 'unknown';
$rateFile = sys_get_temp_dir() . '/ssg_rl_' . md5($ip);
$now = time();
$hits = is_file($rateFile) ? array_map('intval', file($rateFile, FILE_IGNORE_NEW_LINES) ?: []) : [];
$hits = array_values(array_filter($hits, fn (int $t): bool => $now - $t < WINDOW_SECONDS));
if (count($hits) >= MAX_PER_WINDOW) {
    respond(429, ['ok' => false, 'error' => 'Too many enquiries. Please try again in a few minutes.']);
}

$name = clean($data['name'] ?? '', 80);
$phone = clean($data['phone'] ?? '', 20);
$interest = clean($data['interest'] ?? '', 20);
$message = mb_substr(trim((string) ($data['message'] ?? '')), 0, 2000);
$plot = clean($data['plot'] ?? '', 300);
$project = clean($data['project'] ?? '', 100);

if (mb_strlen($name) < 2) respond(422, ['ok' => false, 'error' => 'Please enter your name.']);
if (!preg_match('/^[0-9+\-\s()]{7,20}$/', $phone)) respond(422, ['ok' => false, 'error' => 'Please enter a valid phone number.']);
if (!array_key_exists($interest, INTERESTS)) respond(422, ['ok' => false, 'error' => 'Please choose what you are enquiring about.']);
if (mb_strlen($message) < 5) respond(422, ['ok' => false, 'error' => 'Please write a short message.']);
if ($interest === 'landowner' && mb_strlen($plot) < 3) respond(422, ['ok' => false, 'error' => 'Please tell us about the plot.']);

$hits[] = $now;
file_put_contents($rateFile, implode("\n", $hits), LOCK_EX);

$subject = 'Website enquiry: ' . INTERESTS[$interest] . ($project !== '' ? " ($project)" : '');
$body = "Name: $name\nPhone: $phone\nInterest: " . INTERESTS[$interest] . "\n"
    . ($project !== '' ? "Project: $project\n" : '')
    . ($plot !== '' ? "Plot: $plot\n" : '')
    . "\nMessage:\n$message\n";

$host = preg_replace('/[^a-z0-9.\-]/i', '', preg_replace('/^www\./', '', $_SERVER['HTTP_HOST'] ?? 'localhost') ?? 'localhost');
$headers = "From: SS Garden website <noreply@$host>\r\nContent-Type: text/plain; charset=utf-8";

$sent = getenv('SSG_DRY_RUN') ? true : mail($TO, '=?UTF-8?B?' . base64_encode($subject) . '?=', $body, $headers);
if (!$sent) {
    respond(500, ['ok' => false, 'error' => 'The message could not be sent.']);
}

respond(200, ['ok' => true]);
```

```tsx
"use client";

import Image from "next/image";
import Link from "next/link";
import { motion, useMotionValue, useReducedMotion, useSpring, useTransform } from "motion/react";
import { statusLabel, typeLabel, type Project } from "@/data/types";

export function ProjectCard({ project: p }: { project: Project }) {
  const reduce = useReducedMotion();
  const x = useMotionValue(0);
  const y = useMotionValue(0);
  const rotateX = useSpring(useTransform(y, [-0.5, 0.5], [6, -6]), { stiffness: 150, damping: 18 });
  const rotateY = useSpring(useTransform(x, [-0.5, 0.5], [-6, 6]), { stiffness: 150, damping: 18 });

  function onMove(e: React.PointerEvent<HTMLDivElement>) {
    if (reduce || e.pointerType !== "mouse") return;
    const r = e.currentTarget.getBoundingClientRect();
    x.set((e.clientX - r.left) / r.width - 0.5);
    y.set((e.clientY - r.top) / r.height - 0.5);
  }
  function onLeave() {
    x.set(0);
    y.set(0);
  }

  return (
    <motion.div
      style={{ rotateX, rotateY, transformPerspective: 900 }}
      onPointerMove={onMove}
      onPointerLeave={onLeave}
    >
      <Link href={`/projects/${p.slug}/`} className="group block">
        <div className="relative aspect-[4/3] overflow-hidden bg-surface">
          <Image
            src={p.hero.src}
            alt={p.hero.alt}

        <p className="mt-1 text-muted">{p.address}</p>
```

```tsx
function Tabs<T extends string>({
  label, value, options, onChange,
}: { label: string; value: T; options: { value: T; label: string }[]; onChange: (v: T) => void }) {
  return (
    <div role="group" aria-label={label} className="flex flex-wrap gap-2">
      {options.map((o) => {
        const on = value === o.value;
        return (
          <button
            key={o.value}

            aria-pressed={on}

            className={`h-10 border px-4 text-sm transition active:scale-[0.98] focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-accent ${
```

```tsx
import Image from "next/image";
import { CaretLeft, CaretRight, X } from "@phosphor-icons/react";
import type { ImageRef } from "@/data/types";

export function GalleryLightbox({ images }: { images: ImageRef[] }) {
  const [index, setIndex] = useState<number | null>(null);
  const dialog = useRef<HTMLDialogElement>(null);
  const startX = useRef(0);

  useEffect(() => {
    const d = dialog.current;
    if (!d) return;

    if (index === null && d.open) d.close();
  }, [index]);

  const step = (dir: 1 | -1) =>
    setIndex((i) => (i === null ? i : (i + dir + images.length) % images.length));

  const current = index !== null ? images[index] : null;
  const control =
    "absolute flex h-12 w-12 items-center justify-center bg-bg text-text focus-visible:outline-2 focus-visible:outline-accent";

            key={img.src}
            type="button"
            onClick={() => setIndex(i)}
            aria-label={`Open image: ${img.alt}`}
            className={`group relative aspect-[3/2] overflow-hidden bg-surface focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-accent md:aspect-auto ${

        ref={dialog}
        onClose={() => setIndex(null)}
        onClick={(e) => { if (e.target === dialog.current) setIndex(null); }}

          if (e.key === "ArrowRight") step(1);
```

- [ ] **Step 1: Write the screenshot script**

Create `scripts/screenshots.ts`:

```ts
import fs from "node:fs";
import { chromium } from "playwright";

const BASE = process.env.BASE ?? "http://localhost:4000";
const pages = ["/", "/projects/", "/projects/arboretum-residences/", "/landowners/", "/about/", "/contact/"];
const viewports = [
  { name: "desktop", width: 1440, height: 900 },
  { name: "phone", width: 390, height: 844 },
];

async function main() {
  fs.mkdirSync(".cache/shots", { recursive: true });
  const browser = await chromium.launch({
    args: ["--use-angle=swiftshader", "--enable-unsafe-swiftshader", "--ignore-gpu-blocklist"],
  });
  for (const scheme of ["light", "dark"] as const) {
    for (const vp of viewports) {
      const ctx = await browser.newContext({
        viewport: { width: vp.width, height: vp.height },
        colorScheme: scheme,
      });
      const page = await ctx.newPage();
      for (const p of pages) {
        await page.goto(BASE + p, { waitUntil: "networkidle" });
        await page.waitForTimeout(1500);
        const name = (p === "/" ? "home" : p.replace(/\//g, "_").replace(/^_|_$/g, "")) + `-${scheme}-${vp.name}`;
        await page.screenshot({ path: `.cache/shots/${name}.png`, fullPage: true });
        console.log("shot", name);
      }
      await ctx.close();
    }
  }
  await browser.close();
}

main().catch((e) => { console.error(e); process.exit(1); });
```

````markdown
# SS Garden website

Static Next.js site for SS Garden, a building developer in Dhaka. Output is plain files for cPanel shared hosting.

| Command | What it does |

| `npm run assets:placeholders -- --check` | List image slots that still have no real image |

## Deploy to cPanel

1. Open `public/api/enquiry.php` and set `$TO` to the inbox that should receive enquiries.
2. Run `npm run build`.
3. In cPanel File Manager, open `public_html` and upload the contents of the `out/` folder (including the hidden `.htaccess` file).
4. Turn on SSL in cPanel (AutoSSL) and visit the site over `https://`.
5. Send a test enquiry from the contact page and confirm it arrives. If it lands in spam, ask the host to enable SPF/DKIM for the domain.

The site does not need Node.js on the server. The enquiry script needs PHP 8.0 or newer (choose it in cPanel's MultiPHP Manager).

Edit `src/data/projects.ts`: add one entry with its slug, address, status, type, specs, story, concept and images. Add the matching image slots in `src/data/image-plan.ts`, put the real images in `public/images/projects/<slug>/`, and rebuild.
````
